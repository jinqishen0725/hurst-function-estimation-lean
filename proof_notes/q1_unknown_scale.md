# 一阶差分的未知常尺度：采用同一权重的直接消去

本节补充已有书面证明15–18的Lean实现选择。取原n个中点观测；步长1/n和2/n的一阶差分都保留n−2个共同有效基点。记两组对数统计量为G₁、G₂，其真实期望分别是

m₁ᵢ = log σ² − 2 log n Hᵢ + c + ε₁ᵢ，
m₂ᵢ = log σ² − 2 log n Hᵢ + 2 log 2 Hᵢ + c + ε₂ᵢ。

固定p≥1、0<a≤H≤b<3/4及原Hölder类。已在真实变化Hurst谱模型上证明：对两个固定步长，|εₐᵢ|≤C eₙ，eₙ=(1+log(2n))(n⁻¹+n^(2b−2))；相关平方行和统一有界。这些界也包含网格两端，没有使用平稳模型替代。

把全域粗中点上的局部权重先平均，得到同一个合并权重ν，满足Σν=1、Σ|ν|≤D、max|ν|≤3D/n。定义

sHat = (1−log n/log 2)Σνᵢ log Dᵢ,₁² + (log n/log 2)Σνᵢ log Dᵢ,₂² − c。

此处不需要非线性截断项。Hᵢ在每个基点逐项消去，所以

|E sHat − log σ²| ≤ C log n·eₙ，
Var(sHat) ≤ C log²n/n。

方差通过两个相关统计量的平方和界控制，不需要独立性。由于b<3/4，n eₙ²→0；故充分大n时 E(sHat−log σ²)²/log²n≤C/n。这个更强的界已另列Lean定理，最优风险封装只需其≤C rₙ²推论。

对最终一阶对数局部估计输入减去sHat，作[0,1]截断反演。反演的稳定性常数为1/(2 log n)。比较实际回代与已知尺度估计，再控制相关误差平方和，得到全[0,1]点态MSE≤C rₙ²，rₙ=(n log²n)^(-p/(2p+1))，并传递到全(0,1)上1≤s≤2的平方Ls风险。固定尺度子模型提供相同下界；匹配下界仍要求a<1/2<b。

实现使用全域粗平均，是借助已验证边界权重作出的明确选择；不声称与论文内部区域平均逐样本相同。p=1包含在证明内。高阶矩和极限分布不由本节的二阶矩界推出，仍须继续形式化。
