# q=2 的参数抵消与相关衰减

这里给出接续原20份修复证明的直接证明。固定 `0<a≤H≤b<1`；原 Hölder 类取 `p≥2`，包括整数 `p=2`。常数只依赖固定区间及函数类。

令 `F(h,t)` 为实际归一化谱特征，`S(h,t)` 为其参数一阶展开中的斜率。已在 Lean 验证：

1. `‖F(k,t)−F(h,t)−(k−h)S(h,t)‖₂ ≤ C|k−h|²`，参数及 `|t|≤1` 上统一。
2. `‖S(h,t+δ)−S(h,t)‖₂ ≤ C δ^h(1+|log δ|)`。此处使用实际谱函数的缩放及相位平移；缩放时的 `log δ` 项不能省略。
3. 原 Hölder 类给出 `|H(t+2δ)−2H(t+δ)+H(t)|≤Cδ²`，没有额外假定最高阶导数连续。

写 `h=H(t)`、`d₁=H(t+δ)−h`、`d₂=H(t+2δ)−h`。实际二阶差分与冻结于 h 的二阶差分之差为

```
(d₂−2d₁) S(h,t+2δ)
 + 2d₁ [S(h,t+2δ)−S(h,t+δ)]
 + R₂−2R₁.
```

其中 `‖R_j‖₂≤C|d_j|²`。代入 `|d₁|≤Bδ`、`|d₂|≤2Bδ`，得到

```
‖实际差分−冻结差分‖₂ ≤ C[δ²+δ^(h+1)(1+|log δ|)].
```

乘 `δ^(−h)`，利用 `0<δ≤1` 和 `h<1`，得统一界 `Cδ(1+|log δ|)`。这一合成界已通过 Lean 检查。

## 后续相关行和所需步骤

冻结的两个二阶差分的协方差，是 `x↦x^(h+k)` 的四阶有限差分乘以负的交叉归一化系数。对相隔 d 个网格间隙的差分，四次均值估计给出 `C d^(h+k−4)≤C d^(2b−4)`。相关平方可求和，因为 `4b−8<−4`。

冻结归一化方差为 `4−2^(2h)`，在 `h≤b<1` 上有统一正下界。实际特征误差为 `e_n=O((1+log n)/n)`，故实际协方差扰动为 `O(e_n)`；相关平方行和的附加项为 `O(n e_n²)→0`。上述相关衰减、原类实际行和以及局部对数方差和非线性均值校准均已在第十五阶段通过Lean检查。剩余q=2任务是非线性平滑偏差和最终反演风险。
